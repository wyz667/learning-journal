## 🛠 常用命令速查

```bash
git init                # 创建仓库，只需一次
git status              # 查看当前状态（最安全，随时能敲）
git add .               # 把改动放进暂存区
git commit -m "说明"    # 存成一个永久版本
git log --oneline       # 查看历史记录
git push                # 上传到 GitHub
git pull                # 拉取别人的更新
```

**提交信息规范**

- `feat:` 新功能
- `fix:` 修复 bug
- `docs:` 修改文档
- `test:` 增加测试
- `chore:` 杂项
